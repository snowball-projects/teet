# teet

A snowball toolkit for Twilight's Eve Evo RPG. Keep the original notebooks,
scripts and history as a record of the founder's personal project. Do not remove
historical material just because the dashboard supersedes an entry point.

Read README.md and snowball's canonical principles before product or data changes.
Use lowercase snowball and MIT for original software; game data and third-party
materials keep their own rights. No official affiliation or current game-data
accuracy is implied.

The public dashboard is static. Optimization is exact for the documented linear
weighted model and constraints, not a combat simulator. Check infeasibility,
class/dungeon eligibility and selected totals. No credentials or telemetry.

Desktop automation is Windows-only and explicitly started through the loopback
companion. Never start keyboard/mouse automation during development or tests.
Preserve Host/Origin checks, bounded validated commands, foreground-game checks,
stop controls and synthetic-only tests. The public site cannot control a game.

Run npm test, python3 -m unittest discover -s tests -v and npm run build.
Keep web assets local; no CDN runtime dependencies. Publish only a verified build.
