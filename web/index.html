teet

A personal toolkit built while playing Twilight’s Eve Evo RPG in Warcraft III. It brought together a much-loved game, practical automation and the pleasure of working out a better build.

The optimizer maximizes the original class-weighted stat total using the supplied item snapshot. It is not a combat simulator or a claim about the current game balance. Empty stat cells follow the original model and count as zero. Class restrictions, stacking assumptions and weights are editable in the source data.

All calculations run on this device. No accounts, uploads or analytics. The hosting provider processes ordinary web requests. Desktop automation requires the separate local Windows companion.
